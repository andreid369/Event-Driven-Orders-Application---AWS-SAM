# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting instead: open this repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the impact you expect.

This is a personal learning project maintained on a best-effort basis. I will try to acknowledge reports within a few days.

## Scope

- Vulnerabilities in the code or infrastructure templates in this repository.
- Accidentally committed credentials or personal data.

Out of scope: findings that need access to my AWS account or other systems, and automated scanner output with no demonstrated impact.
